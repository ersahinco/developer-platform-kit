# Local Compose Catalog

`infra/catalog/local-compose/` documents reusable local-runtime building blocks.
These entries help examples and new workloads prove platform behavior locally
before any cloud runtime is involved.

Use this catalog when a developer needs a fast inner-loop proof for a workload
pattern. Do not put use-case-specific dataset names, business events, or schema
semantics here; those belong in the example, app, or data workflow.
